## 📋 执行的检查项

### ✅ 已验证正常
1. **实机PD增益** - 与k1_walk完全相同
2. **默认姿态** - 与k1_walk完全相同

### 🔴 发现的问题

#### 🚨 问题1：准备模式vyaw=0.2（最严重）
**位置**: `tasks/locomotion/nested_locomotion.py:44`
```python
self.processed = [0.0, 0.0, 0.2]  # ⚠️ vyaw非0
```
**影响**: 
- 机器人会尝试原地旋转（~11.5°/s）
- 选择turn模型而非base模型
- 导致启动行为异常

**已提供修复**: 见`fix_k1_loco.sh`

#### ⚠️ 问题2：速度增量限制
**位置**: `tasks/locomotion/nested_locomotion.py:47-52`
**影响**:
- 从0加速到0.5 m/s需要约20步（~0.4秒）
- 比k1_walk慢得多（k1_walk即时响应）
- 可能被用户误判为"不动"

**测试验证**:
```
给vx=0.5命令，实际输出：
Step 0: 0.026 m/s
Step 1: 0.052 m/s
Step 2: 0.078 m/s
...需要约20步达到目标
```

#### ⚠️ 问题3：gravity_offset
**位置**: `tasks/locomotion/nested_locomotion.py:136`
```python
observation[3:6] += [0.015, 0.0, 0.0]
```
**影响**: 需确认训练时是否使用此offset
